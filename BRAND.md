# Strata Works — Brand Identity

**Strata Works** is the professional studio identity of Daniel C. Barletta: biologist,
full-stack software engineer, builder, and worldbuilder.

## The name

*Strata* are layers — geologic beds laid down over deep time, courses of masonry in a
wall, tiers of a software stack, layers of a story. *Works* is both noun and verb: a
body of work, and the plain promise that what we build works. The name joins every
discipline Daniel practices under one structural idea: **good systems are built in
layers, and every layer bears load.**

## Tagline

> **Software, science, and structure — built in layers.**

Short form: *Built in layers.*

## Positioning

A one-person engineering studio with an unusual cross-section: formal training in
biology, a decade of hands-on construction (framing, masonry, landscape), and
production full-stack engineering. Strata Works takes on projects where those layers
compound — scientific interfaces that respect the data, product software that
respects the user, and worlds that respect their own ecology.

## Voice

Precise, grounded, unhurried. Field-notes honesty: say what is measured, label what
is imagined, never dress a prototype as production. Technical terms spelled out.
No hype adjectives; let the direct label on the peak do the talking.

## Visual identity

Evolved from the D.C. Barletta author sites — same geological DNA, engineering-led.

| Token | Value | Role |
|---|---|---|
| Ink | `#0a0c0f` | page ground |
| Basalt | `#12151a` | card / surface |
| Paper | `#e9e4d9` | primary text |
| Muted | `#a8a49c` | secondary text |
| Copper | `#c29b76` | brand accent, rules, eyebrows |
| Data copper | `#c97f33` | chart series 1 (validated vs basalt) |
| Data teal | `#2e9db6` | chart series 2 (validated vs basalt) |
| Seam | `rgba(194,155,118,.25)` | hairline strata boundaries |

**Type.** Space Grotesk leads (400 body, 600 display) — the engineering voice.
Spectral 400 italic appears sparingly as the field-notebook accent (pull quotes,
the "imagined" annotations). This inverts the author sites, where the serif leads.

**Mark.** Four stacked strata bands with one vertical fault seam offsetting the
layers — geology, masonry, stack, and story in a single glyph. Drawn as inline SVG;
the seam is copper, the beds are paper at stepped opacities.

**Motion.** The strata field behind the hero breathes on a slow (~40s) cycle,
transform/opacity only, pausable, honoring `prefers-reduced-motion`.

## Services

1. **Product engineering** — Full-stack React / TypeScript / Node / Next.js
   applications taken from data model to deployed product, end to end.
2. **Scientific dashboards & data visualization** — Hand-built SVG instrumentation
   and telemetry interfaces; colorblind-validated palettes; no chart-library bloat.
3. **Data pipelines & API integration** — Live event ingestion, third-party API
   orchestration, and the full path from raw feed to legible interface.
4. **Operations & trust-and-safety tooling** — Moderation queues, policy workflows,
   and the internal consoles that keep platforms healthy.
5. **Interactive 3D & game systems** — Roblox Studio + Luau gameplay systems and
   Blender asset pipelines, with ecology-driven world logic.
6. **Design-led web presence** — Fast, search-ready marketing sites for studios and
   small businesses, built on the same production discipline as the product work.

**The differentiator:** years of physical construction inform everything — load
paths, tolerances, and the habit of building things that have to stand.

## Project curation rule

One project per skill, chosen for structural bones — never two of the same organ.
Each portfolio entry names the layer it demonstrates.
